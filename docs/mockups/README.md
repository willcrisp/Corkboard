# UI mockups

These files are the sources of the Corkboard design canvas: one `.dc.html` per screen, with `canvas.json` for the layout. They need the canvas runtime to render, so treat them as reference for layout, copy and colour values rather than as pages to open directly.

| File | Screen |
|---|---|
| `Main.dc.html` | Board view (Blizzard templates) |
| `Flat.dc.html` | Flat ElvUI-style skin + pinned MRT-style overlay |
| `Editor.dc.html` | Note editor |
| `Share.dc.html` | Members tab + popups |
| `SyncStates.dc.html` | Status line, alerts, chat output, minimap tooltip |
| `Debug.dc.html` | `/cork debug` panel |

The style rules they follow are summarised in `../ui-style.md`.
